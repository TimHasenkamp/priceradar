# PriceRadar API (v1)

Base path: `/api`. All bodies are JSON (`Content-Type: application/json`).
All money values are **integer cents**. All timestamps are **RFC 3339 UTC** strings.
Nullable fields are always present and `null` when unknown.

## Errors

Every non-2xx response has this shape:

```json
{ "error": { "code": "not_found", "message": "product 42 not found" } }
```

| HTTP | code               | when |
|------|--------------------|------|
| 400  | `invalid_request`  | malformed JSON, bad id, bad query param, invalid URL |
| 404  | `not_found`        | product does not exist |
| 409  | `duplicate`        | product with that URL already exists |
| 409  | `not_configured`   | `POST /api/notifications/test` without `PR_GOTIFY_URL` / `PR_GOTIFY_TOKEN` |
| 422  | `unsupported_shop` | no scraper supports the URL's host |
| 502  | `scrape_failed`    | fetching/parsing the shop page failed (message starts with the error kind) |
| 502  | `notify_failed`    | Gotify rejected or did not answer the test message (message has the reason) |
| 502  | `backend_unreachable` | only generated by the web proxy when the Go backend is down |
| 503  | `unavailable`      | server is shutting down |
| 504  | `timeout`          | refresh/add did not finish in time |
| 500  | `internal`         | anything else |

## Types

### Product

```json
{
  "id": 1,
  "shop": "otto",
  "url": "https://www.otto.de/p/bambu-lab-3d-drucker-a1-combo-CS00EO0AU/",
  "sku": "S8Z7V9T27LCL",
  "name": "Bambu Lab 3D-Drucker A1 Combo",
  "original_name": "Bambu Lab 3D-Drucker A1 Combo",
  "custom_name": null,
  "image_url": "https://i.otto.de/i/otto/....jpg",
  "currency": "EUR",
  "target_price_cents": 45000,
  "target_reached": false,
  "paused": false,
  "notify": true,
  "created_at": "2026-11-11T14:00:00Z",
  "last_checked_at": "2026-11-11T14:00:00Z",
  "last_success_at": "2026-11-11T14:00:00Z",
  "consecutive_failures": 0,
  "last_error_kind": null,
  "last_error": null,
  "stats": {
    "current_cents": 49360,
    "previous_cents": 51990,
    "avg30_cents": 50120,
    "min_cents": 47999,
    "max_cents": 55900,
    "old_price_cents": null,
    "rrp_cents": null,
    "availability": "in_stock"
  }
}
```

- `name` = `custom_name ?? original_name` (display name).
- `stats.current_cents`: price of latest successful check.
- `stats.previous_cents`: latest successful price that **differs** from the current one (null if the price never changed).
- `stats.avg30_cents`: mean of successful check prices over the last 30 days (rounded).
- `stats.min_cents` / `max_cents`: over all successful checks.
- `old_price_cents` (Streichpreis) / `rrp_cents` (UVP) / `availability`: from the latest successful check.
- `availability` ∈ `in_stock | out_of_stock | preorder | limited | unknown`.
- `target_reached`: `target_price_cents != null && current_cents != null && current_cents <= target_price_cents`.
- `notify`: whether notifications are evaluated for this product (default `true`). Paused products never notify.
- `last_error_kind` ∈ `blocked | layout_changed | not_found | transient | robots_disallowed | internal`.

### PricePoint

```json
{ "checked_at": "2026-11-11T14:00:00Z", "price_cents": 49360, "old_price_cents": null, "rrp_cents": 36900, "availability": "in_stock" }
```

### Check (one scrape attempt, success or failure)

```json
{ "id": 7, "checked_at": "...", "success": false, "price_cents": null,
  "error_kind": "layout_changed", "error_message": "no Product JSON-LD and no price block", "duration_ms": 8123 }
```

### Notification

One notification event of a product. Events are recorded even when Gotify is not configured (`status: "skipped"`), so the log shows what would have been sent.

```json
{ "id": 12, "kind": "price_drop", "title": "Preis gesunken: Bambu Lab A1 Combo (−10,0 %)",
  "message": "**Bambu Lab A1 Combo**

Der Preis ist gesunken.

- Aktueller Preis: **449,99 €**
…",
  "priority": 6, "status": "sent", "error": null,
  "created_at": "2026-11-11T14:00:00Z", "sent_at": "2026-11-11T14:00:01Z" }
```

- `kind` ∈ `target_reached | price_drop | price_rise | new_low | trend_down | trend_up | back_in_stock | out_of_stock | scrape_failing`. A check that is both a new low and a significant drop produces one `new_low` message.
- `message`: Markdown (German).
- `priority`: Gotify priority (target_reached 8, price_drop/new_low/back_in_stock 6, scrape_failing 5, trend_down 4, price_rise/out_of_stock 3, trend_up 2).
- `status` ∈ `pending` (queued for sending, normally only for seconds) `| sent | failed | skipped`. `error` is set for `failed`.
- `created_at` is the time of the check that triggered the event; `sent_at` is set once Gotify accepted it.

## Endpoints

| Method | Path | Body / Query | Response |
|---|---|---|---|
| GET    | `/api/products` | – | `200 Product[]` (sorted by created_at desc) |
| POST   | `/api/products` | `{"url": "...", "target_price_cents": 45000?}` | `201 Product` – fetches the page synchronously (10–60 s) |
| GET    | `/api/products/{id}` | – | `200 Product` |
| PATCH  | `/api/products/{id}` | any of `{"custom_name": "x"\|null, "paused": true, "notify": false, "target_price_cents": 123\|null}` – absent = unchanged, `null` = clear (`paused` and `notify` reject `null`) | `200 Product` |
| DELETE | `/api/products/{id}` | – | `204` |
| GET    | `/api/products/{id}/prices` | `?from=RFC3339&to=RFC3339` (both optional) | `200 PricePoint[]` ascending, successful checks only |
| GET    | `/api/products/{id}/checks` | `?limit=50` (1..500) | `200 Check[]` newest first, incl. failures |
| POST   | `/api/products/{id}/refresh` | – | `200 {"product": Product, "check": Check}` – runs synchronously through the serial scrape queue. A failed scrape still returns 200 with `check.success=false`. |
| GET    | `/api/products/{id}/notifications` | `?limit=50` (1..500) | `200 Notification[]` newest first |
| POST   | `/api/notifications/test` | – | `200 {"status":"sent"}` – sends a test message via Gotify synchronously. `409 not_configured` without Gotify, `502 notify_failed` if Gotify fails |
| GET    | `/api/healthz` | – | `200 {"status":"ok","db":"ok","fetcher":"ok"\|"down","gotify":"configured"\|"not_configured"}` – Gotify is not contacted |
